Dor4ek ESP — Minecraft 1.21.11 / Fabric / Java 21

Сборка:
1. Установи JDK 21 и Gradle.
2. Открой папку проекта в IntelliJ IDEA или терминале.
3. Выполни: gradle build
4. Готовый JAR появится в build/libs/.
5. Положи JAR в папку .minecraft/mods вместе с Fabric API.

Управление:
- 0 — открыть меню.
- Players / Mobs / Animals — независимые переключатели.
- ALL — включить все три категории.
- Выключить всё — отключить подсветку.

Настройки хранятся в config/dor4ek-esp.properties.

Это клиентский мод. В сетевой игре подсветка применяется только к сущностям,
которые уже загружены клиентом. Он не загружает сущности из неизвестных областей.
